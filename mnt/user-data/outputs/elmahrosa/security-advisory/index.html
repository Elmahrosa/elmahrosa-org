Fake "Claude for Windows" malware campaign on Facebook

A paid advertising campaign on Meta (Facebook) is impersonating Anthropic PBC and the Claude brand to distribute a malicious Windows installer. The ad campaign routes victims to a typosquat domain and delivers a file almost certainly designed to steal credentials, browser sessions, cryptocurrency wallets, and developer account access.

✓ Official. Legitimate. Verified.
The only legitimate Claude for Windows installer is at: https://claude.ai/download

Campaign overview

The scam operates via paid Meta advertising. The ad creative uses Anthropic's actual visual assets — the Claude wordmark, the burst icon, and a screenshot of the Claude desktop UI — to appear legitimate. At the bottom of the ad creative, the displayed link reads CLAUDE.COM, but the actual click destination is the typosquat domain clude-promo-offer.com.

This is a classic Facebook ad cloaking pattern — displaying one domain while routing to another — which bypassed Meta's automated ad review. The ad ran under sponsor name "BlockFlow", which has no relationship with Anthropic.

The campaign targets MENA-region Facebook users with interest in AI, technology, and Windows applications. Given the profile of likely victims — developers, founders, AI practitioners — the malware is almost certainly designed to harvest browser-saved credentials, GitHub/Anthropic/Hostinger/domain-registrar session tokens, and cryptocurrency wallet seeds.

⚠ Do not

Do not visit clude-promo-offer.com. Do not download or execute installer.exe from this domain. Do not enter credentials on any page served from this domain. If you have already downloaded the file: do not open it. Delete it immediately and empty the Recycle Bin.

Why this attack is effective

The campaign is technically sophisticated. The scammers correctly identified that:

  • Facebook's ad review automation scans the displayed domain (claude.com — legitimate), not the destination domain (clude-promo-offer.com — malicious).
  • The target audience (MENA AI practitioners) is actively seeking Claude-related tools and is familiar with the Anthropic brand.
  • The ad creative quality is high — Anthropic's actual assets were lifted and reproduced accurately, making the ad indistinguishable from a legitimate promotion to a non-expert eye.
  • The typosquat domain differs from the legitimate brand by a single character — a common phishing technique that exploits visual scanning speed.

If you have already downloaded the file

  1. 01Do not open the file. Delete it immediately from your Downloads folder. Empty the Recycle Bin.
  2. 02Disconnect from the internet if you opened the file, to prevent credential exfiltration.
  3. 03Run a full scan with Windows Defender: Settings → Windows Security → Virus & Threat Protection → Scan options → Full scan. Then a second-opinion scan with Malwarebytes Free.
  4. 04Change passwords from a clean, separate device: Anthropic Partner Portal, all Gmail accounts, Hostinger, GitHub, LinkedIn, any crypto wallet recovery phrase.
  5. 05Revoke active sessions in Gmail (Security → Your devices), GitHub (Settings → Sessions), and Anthropic Console (Settings → API Keys).
  6. 06Enable hardware security keys or app-based 2FA (not SMS) on your highest-risk accounts (GitHub, Google, Anthropic).

Actions already taken by Elmahrosa International

  • ✓Reported the ad to Meta via the "Report Ad" flow — categories: Scam or Fraud and Misleading.
  • ✓Posted a public warning comment under the Facebook ad post, redirecting users to the official claude.ai/download URL, signed with CPN-member credentials.
  • ✓Sent formal security report to Anthropic (security@anthropic.com) with full IOCs, requesting legal takedown to Meta and WHOIS abuse report to registrar.
  • ✓Submitted malicious domain to Google Safe Browsing for blacklisting across Chrome globally.

How to verify a Claude download is legitimate

The only legitimate Claude-branded downloads and services are hosted on the following Anthropic-controlled domains:

  • claude.ai — Main Claude web app and download portal
  • anthropic.com — Official company website
  • claude.com — Anthropic-owned redirect domain

Any domain that deviates from the above — different TLD, extra hyphens, missing characters, added words — should be treated as malicious. When in doubt, type the URL directly into your browser rather than clicking any link or advertisement.
