Product Relationships

Nubia ↔ Sentinel

Nubia consumes Sentinel policies for AI prompt filtering. Sentinel audits all Nubia API calls for anomaly detection and threat scoring.

Meridian ↔ Zephyr

Meridian streams transaction events to Zephyr for real-time analytics. Zephyr provides revenue forecasting back to Meridian dashboards.

Beacon → All Products

Beacon enforces compliance posture across every product surface. Audit logs are aggregated centrally for regulatory reporting.

Atlas → Infrastructure

Atlas orchestrates provisioning, scaling, and teardown across all services. It interfaces with cloud providers and edge nodes.

Security Model

  • Layer 1 — Edge WAF & DDoS Mitigation — blocks volumetric attacks before they reach the stack
  • Layer 2 — Rate Limiting & Throttling — per-IP, per-key, per-user rate enforcement
  • Layer 3 — Authentication & Authorization — OAuth 2.0 / OIDC with MFA support
  • Layer 4 — Encryption — AES-256 at rest, TLS 1.3 in transit, key rotation every 90 days
  • Layer 5 — Application Security — input validation, CSP headers, SQL injection prevention
  • Layer 6 — Monitoring & Response — Sentinel Shield with 25 detection rules, real-time alerting
